# Physio Atlas

A personal, visual medical and physiotherapy textbook. Built as a lightweight static web app that can be hosted with GitHub Pages.

## Features
- Organise condition chapters by body system
- Editable condition templates: definition, causes, signs, assessment, management and complications
- Upload images and paste copied images into a chapter
- Rich personal notes
- Drawing sketchbook with pen, colour, eraser and undo
- Create and review active-recall flashcards
- Bookmarks, search, and library overview
- Learning hub: anatomy, biomechanics, special tests, exercise prescription, neurology, gait and posture, evidence-based practice
- Clinical case simulations, OSCE checklists, mixed-topic quizzes and editable rehabilitation treatment plans
- Export and import a JSON backup

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will publish the site at the Pages URL shown there.

## Data and privacy
The app stores notes, images, cards and sketches in the browser's local storage. Data is not automatically synced between devices. Export backups regularly. Avoid storing patient-identifiable information. Large image collections can exceed browser storage limits.

## Medical disclaimer
This is a personal educational note-taking tool, not a clinical decision-support system. Seed notes are brief study prompts, not exhaustive clinical guidance. Verify clinical content against current evidence, local protocols and qualified supervision before applying it in practice.


## Version 2 additions
- Brighter, more colourful visual theme with pastel system accents and gradient highlights.
- Dedicated **Articles & critical appraisal** workspace with editable article records.
- Structured journal-club worksheet: research question, design, participants, intervention/comparator, outcomes, results, strengths, limitations, validity, applicability and practice implications.
- Expanded condition chapter template with red flags, differential diagnosis, special tests, outcome measures, rehabilitation progression, precautions and evidence notes.
- Article critiques are included in JSON export/import backups.

## Article appraisal reminder
Use the appraisal checklist that matches the study design (for example CASP, PEDro, CONSORT, STROBE or PRISMA). Record the article's actual findings rather than relying on an abstract alone. This tool does not automatically verify papers or calculate risk of bias.


## Expanded topic library
The library includes a further batch of 29 editable topic templates. From the main library, choose **Add 29 more topics**. Each topic includes a concise overview, clinical assessment prompts, red flags, management and rehabilitation considerations, outcome measures, special tests/differentials where relevant, and complications. These are educational starting points, not patient-specific protocols.
